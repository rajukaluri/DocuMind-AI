# DocuMind AI

Upload a PDF and ask grounded questions about its contents using Gemini embeddings, ChromaDB, and LangChain.

## Required Space secret

Add `GOOGLE_API_KEY` under the Space Settings > Variables and secrets panel. Do not commit `.env` files or API keys.
